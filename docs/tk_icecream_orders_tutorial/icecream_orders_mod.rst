==========================
Ice cream orders
==========================

| Build an **Ice Cream Shop** app with Python and Tkinter.
| Pick a flavour, container and topping, see the price, and add ice creams to an order.
| At the end, you change the app to sell **your own product**.

.. image:: images/icecream_08.png
    :scale: 67

----

What you will learn
----------------------

- A **dictionary** stores choices and prices: ``"Vanilla": 4.00``
- A **list** stores the order: ``orders.append(ice_cream)``
- Code goes in **5 sections**: imports, data, constants, definitions, widgets.
- Each widget is **created**, **positioned**, then **configured**.

----

How each lesson works
----------------------

#. Read the short explanation.
#. Copy each code block **in order** and paste it where the step says.
#. Run the app and check it looks like the picture.
#. Do the quiz.
