==========================
Ice cream orders
==========================

| In this tutorial you build an **Ice Cream Shop** ordering app with Python and Tkinter.
| The user picks a flavour, a container and a topping, sees the price, and adds ice creams to an order.
| The app keeps a running total, and the user can remove one ice cream or clear the whole order.
| When the tutorial is finished, you change the app into an ordering app for **your own product**.

What you will learn
----------------------

- How a **dictionary** stores choices and their prices, e.g. ``"Vanilla": 4.00``.
- How a **list** stores every ice cream in the order, e.g. ``orders.append(ice_cream)``.
- How to set out a program in the right **order**: imports, dictionaries, constants, definitions, then widgets.
- How to group the code for each widget: **create** it, **place** it with ``grid()``, **configure** its text, colour and font, then **bind** its variable.
- How to use radio buttons, drop-down menus, buttons, labels and a listbox.
